# Sky Pulse — Smart Weather App

A React weather app with live conditions, hourly/3-day forecasts, sun & moon tracking, weather alerts, and a map view — powered by [wttr.in](https://wttr.in) and [Open-Meteo](https://open-meteo.com).

## Run locally

```bash
npm install
npm start
```

Opens at [http://localhost:3000](http://localhost:3000).

## Build for production

```bash
npm run build
```

Outputs a deployable static site to `build/`.
